# Heavy Emerald VPN

Кроссплатформенный VPN-клиент на Flutter (Dart) с ядром sing-box.

## Возможности

- VLESS + Reality
- TUN-режим на Windows (wintun)
- Split Tunneling: по приложениям и доменам
- Проверка задержки серверов (TCP / HTTP / ICMP)
- Подписки и оплата через YooKassa (через собственный backend)
- Управление клиентами через панель 3X-UI
- Автообновление через GitHub Releases
- Тёмная glassmorphism-тема, адаптивный интерфейс
- Анимированный воксельный кристалл и кастомные painter'ы

## Стек

- Flutter / Dart
- sing-box
- wintun
- YooKassa API
- 3X-UI Panel
- SharedPreferences
- http, package_info_plus, crypto, path_provider
